# Progressive Web App

WSync-LED can be installed on any of you device which support PWA and service-workers.


## Install on a desktop

Open WSync-LED in your favorite browser, click the install button and follow instructions to install the PWA.
<img src="../assets/install-pwa-desktop.png" style="border-radius:10px">

> [!IMPORTANT]
> Progressive Web Apps can only be installed via a secure connection and are not necessarily installable
> from all sources.

> [!TIP]
> You can counter this behavior by running `npm run preview` and opening WSync-LED on `localhost`, you will then be able to install the PWA. You may also serve the app from a secured connection.
> Since **`v2.0.0`**, a public build of WSync-LED is available on [Github Pages](https://antonin1106.github.io/WSync-LED/wsync.html), it is just a static file, your data are always kept on your device !

## Install on iPhone

Serve WSync-LED from a local source on your network (run `npm run preview` or use a  local server) or access it from [Github Pages](https://antonin1106.github.io/WSync-LED/wsync.html).

Then open WSync-LED on Safari, click the share button, then `Add to home screen`.
You can change the app name as you want.
